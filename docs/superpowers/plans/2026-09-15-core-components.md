# PraSanghi Core Components Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Also required throughout execution, per the project's design documentation:**
> - `shadcn` skill — before adding/editing any shadcn component, run `npx shadcn@latest docs <component>` and follow its composition/styling rules (semantic tokens, `FieldGroup`/`Field`, `data-icon`, no `space-x-*`/`space-y-*`, etc.)
> - `better-colors` skill — if any new color is ever introduced beyond the tokens defined in Task 5, convert it to OKLCH and check hue-drift/contrast before adding it.
> - `better-typography` skill — if any new text treatment is introduced, follow the rules already encoded in `design/typography.md` §9 (tabular numbers, `text-wrap`, 16px mobile inputs, etc.).
> - `fixing-accessibility` skill — run before Task 19's final verification step, auditing every component built in this plan against WCAG 2.1 AA.
> - `frontend-design` skill — re-read before Task 19's visual smoke test; check the assembled homepage against its anti-generic-AI-tell checklist (no default warm-cream+terracotta look, no SaaS-card kit, no scattered fade-in-on-scroll).

**Goal:** Stand up the PraSanghi Next.js project and build every shared "Core Component" defined in `planning/components.md` §1–§13, culminating in a placeholder homepage that visually proves out the full design system (`design/design-system.md`, `design/typography.md`, `design/color-system.md`) end to end.

**Architecture:** Next.js 15 (App Router, TypeScript, `src/` directory) + Tailwind CSS v4 (CSS-first `@theme` config) + shadcn/ui (Radix primitives) for accessible primitives (Dialog, Sheet, DropdownMenu), with Zustand for the one piece of cross-component client state this phase needs (the BCI disclaimer's session-acknowledgment flag), and Vitest + React Testing Library for logic- and accessibility-bearing components. Pages that consume real content (Practice Areas, People, Insights, Contact, etc.) are explicitly out of scope — this plan builds the shared component layer and a placeholder homepage only, per `build/implementation-roadmap.md` Phase 6.

**Tech Stack:** Next.js 15, TypeScript, Tailwind CSS v4, shadcn/ui (Radix base), Zustand, lucide-react, Vitest, @testing-library/react, @testing-library/jest-dom, @testing-library/user-event, jsdom.

```ts
import { create } from 'zustand'
import { persist, createJSONStorage } from 'zustand/middleware'

interface DisclaimerState {
  acknowledged: boolean
  acknowledge: () => void
}

export const useDisclaimerStore = create<DisclaimerState>()(
  persist(
    (set) => ({
      acknowledged: false,
      acknowledge: () => set({ acknowledged: true }),
    }),
    {
      name: 'prasanghi-bci-disclaimer',
      storage: createJSONStorage(() => sessionStorage),
    }
  )
)
```

```tsx
} from '@/components/ui/dialog'
import { Button } from '@/components/ui/button'
import { useDisclaimerStore } from '@/store/disclaimer-store'

const DISCLAIMER_TEXT =
  'The Bar Council of India does not permit advocates to solicit work or advertise. By proceeding, you confirm that you are seeking information about PraSanghi of your own accord, that there has been no solicitation or invitation of any kind from PraSanghi or its members, and that the contents of this website are for informational purposes only and do not constitute legal advice. No lawyer-client relationship is created by accessing this website.'

export function BciDisclaimerModal() {
  const acknowledged = useDisclaimerStore((state) => state.acknowledged)
  const acknowledge = useDisclaimerStore((state) => state.acknowledge)
  const [hydrated, setHydrated] = useState(false)

  useEffect(() => {
    setHydrated(true)
  }, [])

  const handleCancel = () => {
    window.location.href = 'https://www.barcouncilofindia.org/'
  }

  if (!hydrated) return null

  return (
    <Dialog open={!acknowledged}>
      <DialogContent
        showCloseButton={false}
        onEscapeKeyDown={(event) => {
          event.preventDefault()
          handleCancel()
        }}
        onPointerDownOutside={(event) => event.preventDefault()}
        className="sm:max-w-lg"
      >
        <DialogHeader>
          <DialogTitle className="font-serif">Disclaimer</DialogTitle>
          <DialogDescription className="text-left text-body-md text-muted-foreground">
            {DISCLAIMER_TEXT}
          </DialogDescription>
        </DialogHeader>
        <DialogFooter className="flex-row justify-end gap-3">
          <Button variant="outline" onClick={handleCancel}>
            Cancel
          </Button>
          <Button onClick={acknowledge}>I Agree</Button>
        </DialogFooter>
      </DialogContent>
    </Dialog>
  )
}
```

**Design note (Cancel behavior):** `planning/pages.md` §16 requires Cancel to exit to "a neutral holding state... never silently dismissing the disclaimer." Redirecting to the Bar Council of India's own public site satisfies this: the visitor leaves PraSanghi's site entirely rather than the modal simply closing with content still exposed underneath.
